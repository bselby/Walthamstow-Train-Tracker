# E17 Trains Redesign Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild the look, drawings, screens and wording of the whole app to the approved Picture book design, on one branch, released in one approved merge.

**Architecture:** Logic stays (`tapStore.ts`, `tap.ts`, `season.ts`, the pollers, routing pattern); presentation is replaced. New pure modules for drawings (`trainArt.ts`), the line diagram layout (`lineDiagram.ts`), timing copy (`tapCopy.ts`) and two new screens (`ticketPage.ts`, `howItWorks.ts`). Every pure function gets a vitest test; DOM builders are tested with jsdom as today.

**Tech Stack:** Vite 7, plain TypeScript, CSS, vitest + jsdom, vite-plugin-pwa, Netlify.

**Spec:** `docs/superpowers/specs/2026-11-18-redesign-design.md` (approved 18 Nov 2026). Brief: `docs/design/2026-11-18-ux-strategy-and-design-brief.md`. Boards: canvas https://claude.ai/artifact/8i8eF18Eqd2juab32MbVbG; local copies of every board's HTML are in the session scratchpad `redesign/project/` (C2-*, C3-*, C4-*). Open them in a browser for exact layout, sizes and copy. Board numbers below match the canvas titles (1 to 19).

## Global Constraints

- All work on branch `redesign` in its own worktree. Never push, open a PR or merge without Ben's explicit yes for that step.
- `npm test` and `npm run build` green at every commit. Tests that check old wording or markup are rewritten to the new design, never deleted without replacement.
- `localStorage` keys unchanged (`wtt_tap_state`, the favourites key). New tap-state fields are optional with safe defaults.
- Colours (light): bg `#DCEEF5`, card `#FFFFFF` radius 22px, ink `#1F2A44`, dim `#46536E`, Weaver `#7A2E54`, Suffragette `#1E7B4B`, yellow `#FFC93C`, ticket cream `#FFF4CF`, pin `#E4572E`, freight brown `#8A5A2B`, container teal `#2F7D8C`, freight tag bg `#F3E6D8` text `#6B4A1E`.
- Colours (dark, via `prefers-color-scheme: dark`, no in-app switch): bg `#121829`, card `#1D2539`, border `#3A4560`, text `#F2F4F8`, dim `#A9B3C6`, Weaver text `#E79BC0`, Weaver doors `#B4517F`, pin `#F0663F`.
- Fonts: Baloo 2 (600/700/800) for headings and numbers, Nunito (500–800) for body, from Google Fonts. Big Shoulders removed everywhere.
- Copy: British English, no exclamation marks, "spot" not "viewpoint", no technical or data detail on app screens (that lives on the privacy page).
- Line diagram rule: both end stations as larger dots with full names under the line; every station between as a small dot; a "You" pin at the spot; no per-spot drawings.
- Countdown numbers of both directions visible without scrolling in a 320 × 460 px visible area; 44px minimum targets; reduced motion respected; screen reader labels on every drawing that carries meaning.
- No Undo after a tap. No ticket number.
- Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A returning visitor whose saved tap state predates `spotsTimed` (or is `declined`, or has 60+ taps) loads without error and sees the right badge: test in Task 4.
2. A tap with no signal still clips the ticket and shows the no-signal line: test in Task 4 and Task 7.
3. Queens Road (no timing button) shows no placeholder or button, but still shows the ticket badge: test in Task 7.
4. Opening `/ticket` or `/how-it-works` directly, with no spot behind it, Back goes home: test in Task 5.
5. On a 320 × 460 viewport with the yellow button showing, both countdown numbers stay on screen: measured in Task 13.
